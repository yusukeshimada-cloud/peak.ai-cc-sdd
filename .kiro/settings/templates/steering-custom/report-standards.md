# Report Standards

[Purpose: capture shared report/export rules such as encoding, formatting, naming, and common layout]

## Scope
- CSV / PDF / Excel style outputs if the project has report-style exports
- Shared file naming, text encoding, and common formatting
- Common header / footer or metadata rules across reports

## File Format Rules
- Declare the default output format(s) explicitly
- Declare character encoding explicitly for text outputs
- Declare how download filenames are determined

## Common Formatting
- Declare common date format
- Declare common number format
- Declare decimal / separator conventions when relevant

## Common Layout / Metadata
- If reports share headers or footers, document them explicitly
- If reports are simple data exports, state that there is no decorative shared layout
- Document common metadata such as export timestamp or filter conditions if included

---
_Focus on shared report/export rules, not per-report field catalogs._
